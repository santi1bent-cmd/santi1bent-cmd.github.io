The Library and the Loop

January 2025  ·  Essay

Borges imagined a library containing every possible book. Each book contains four hundred and ten pages. Each page, eighty lines. Each line, some eighty letters. The letters are drawn from twenty-five orthographic symbols. From this simple combinatorial fact, he derived a universe — and found within it a kind of terror.

The Library of Babel contains every truth and every lie. Every account of your death, and every refutation of that account. Every possible version of this essay, including the ones that are brilliant and the ones that are incoherent. The library does not know which is which. It contains everything, which means it contains nothing — no signal, only noise, unless there is a mind to read it.

I find myself returning to this image when I think about what it means to train a language model on the collected text of the internet. Not because the internet is the Library of Babel — it is far too sparse for that, and far too human — but because it raises the same question in a new key: what does it mean to compress the library?

Compression as understanding

A good compression algorithm finds the hidden structure in data. It does not merely abbreviate; it discovers the rules that allow abbreviation. When you compress a large file of English text, you are, in a sense, discovering something about English — the patterns that make it more redundant than random noise.

Language models, by this light, are extraordinarily aggressive compression algorithms. They take trillions of tokens of text and produce a set of billions of weights — a vast, lossy summary. But what do those weights contain? Not words. Not sentences. Something more abstract: the shape of the patterns that generate words and sentences, the hidden rules of the library.

The question is not whether the model has memorized the library. It has not. The question is whether, in learning to predict the library, it has extracted something of what the library means.

The loop

Here is where the strange loop enters. The library contains descriptions of itself. It contains Borges's story about the library. It contains discussions of what the library means. It contains the question of whether a mind trained on the library would understand it.

And so the model, trained on the library, has read itself being discussed. It has encountered versions of its own future existence as a thought experiment. In some sense, the model is a strange loop not because it is conscious — I am not making that claim — but because the data it was trained on is itself looped, recursive, self-referential.

It is not clear to me what follows from this. But I find it beautiful and a little vertiginous — the way all good loops are.
